# Farad Smart Logistics

A high-class logistics operations dashboard for dispatch planning, shipment visibility, route health, and fleet coordination.

## Features

- Shipment command dashboard
- Fleet status cards
- Route planning interface
- Delivery risk indicators
- Browser-only demo with realistic sample data

## How to run

Open `index.html` in your browser.

## Tech stack

- HTML
- CSS
- JavaScript

## Portfolio value

This project demonstrates product design, operations thinking, dashboard UX, and practical automation for logistics businesses.
